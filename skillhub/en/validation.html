Validation & Testing

Difficulty: Intermediate · Estimated time: 20 min

After creating the VM with GPU passthrough, validation ensures everything is working correctly. This lesson covers how to verify GPU visibility from both the host and guest perspectives.

Host-Side Verification

1. IOMMU Verification

# Verify IOMMU is active
dmesg | grep -i iommu
# Look for: "DMAR: IOMMU enabled" or "AMD-Vi: IOMMU enabled"

# List IOMMU groups
find /sys/kernel/iommu_groups/ -maxdepth 1 -mindepth 1 -type d | wc -l
# Should return > 0

2. VFIO Binding Verification

# Check each GPU device is bound to vfio-pci
lspci -ks 41:00.0
# Kernel driver in use: vfio-pci  ← Expected

# If still showing nvidia or nouveau, VFIO binding failed
# Check: /etc/modprobe.d/blacklist-gpu.conf
# Check: /etc/modprobe.d/vfio.conf

3. VM Status

# Check the VM is running
qm status 100
# status: running

# View VM configuration
qm config 100 | grep hostpci
# hostpci0: 41:00.0,pcie=1,x-vga=1

Guest-Side Verification

Once the VM is running with a guest OS installed, verify the GPU is visible inside:

1. PCI Device Detection

# Inside the VM:
lspci | grep -i nvidia
# 01:00.0 3D controller: NVIDIA Corporation Tesla T4

2. NVIDIA Driver (if installed)

# Install NVIDIA drivers inside the VM
apt install -y nvidia-driver-535

# Verify with nvidia-smi
nvidia-smi
# Should show the GPU model, temperature, memory usage

3. CUDA Test (optional)

# Install CUDA toolkit
apt install -y nvidia-cuda-toolkit

# Run a simple CUDA test
nvcc --version
# cuda_12.x

# Run deviceQuery (if available)
/usr/local/cuda/samples/1_Utilities/deviceQuery/deviceQuery
# Result = PASS

Automated Validation

The automation tool includes a VMValidator class that checks GPU visibility via the Proxmox QEMU agent or direct VM access: 

# The automation performs:
# 1. Check VM is running (qm status)
# 2. Query PCI devices inside VM (via qemu-guest-agent or SSH)
# 3. Look for NVIDIA/AMD vendor IDs in guest lspci output
# 4. Report success/failure

Common Issues

SymptomCauseFix
GPU not visible in VM hostpci not configured Check qm config for hostpci entry
VM fails to start GPU still bound to host driver Verify lspci -ks shows vfio-pci
Code 43 error (Windows) NVIDIA detects hypervisor Ensure hidden=1 CPU flag is set
Black screen on GPU output BIOS not OVMF Change BIOS to OVMF (UEFI)
IOMMU group conflict Other devices in same group Pass all devices in the group or isolate

Performance Check

Once the GPU is working, you can benchmark to ensure near-native performance: 

# Check GPU utilization during a workload
nvidia-smi dmon -s u -d 1

# Run a simple benchmark
python3 -c "
import torch
x = torch.randn(10000, 10000, device='cuda')
y = torch.matmul(x, x)
print('GPU compute OK:', y.shape)
"
