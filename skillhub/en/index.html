Proxmox VE GPU Passthrough on OVH Baremetal

Welcome to SkillHub, the hands-on training companion for the opcp-proxmox-install project. This course walks you through deploying Proxmox VE on OVHcloud baremetal instances and configuring GPU PCI passthrough for high-performance VM workloads.

Context

You have access to an OVHcloud OpenStack project with baremetal (GPU) nodes. Using our automation tooling, you will provision a Debian-based instance, install Proxmox VE, configure IOMMU and VFIO for GPU isolation, and create a VM with direct GPU access — all automated via a single CLI command.

What You Will Learn

By the end of this training path you will be comfortable with:

  • Core Concepts — Proxmox VE architecture, PCI passthrough fundamentals, and IOMMU groups
  • Baremetal Provisioning — creating instances on OVHcloud OpenStack with GPU flavors
  • Proxmox Installation — automated Proxmox VE deployment on Debian
  • GPU Passthrough — IOMMU configuration, VFIO driver binding, and device isolation
  • VM Creation — creating Q35/OVMF VMs with hostpci GPU devices
  • Validation — verifying GPU visibility inside VMs

Prerequisites

  • Basic familiarity with a terminal / command line
  • Python 3.9+ installed
  • An OVHcloud Public Cloud project with baremetal GPU access

Quick Start

Install the automation tool and run the full workflow:

# Clone the project
git clone https://forgejo.example.com/opcp-proxmox-install.git
cd opcp-proxmox-install

# Install in a virtual environment
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# Run the automation (dry-run first)
proxmox-install --config config.yaml --dry-run

# Execute the full build
proxmox-install --config config.yaml
