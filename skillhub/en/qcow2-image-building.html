Proxmox qcow2 Image Building

Difficulty: Advanced · Estimated time: 40 min

Overview

This lesson covers the Python SDK approach for building Proxmox VE qcow2 disk images on OVH OpenStack. The pipeline orchestrates a multi-step workflow: create a temporary SLES build instance, download the Proxmox ISO, convert it to qcow2 format using qemu-img, create a snapshot, and upload the final image to OpenStack Glance.

By the end of this lesson, you will understand how to automate the entire image building process using the OpenStack SDK Python API and the build-image CLI subcommand.

Prerequisites

  • OpenStack credentials (application credentials or username/password)
  • Python 3.9+ with openstacksdk installed
  • An SSH key pair registered in OpenStack
  • Access to a SLES base image in OpenStack Glance
  • Familiarity with Baremetal Provisioning concepts

Step-by-step Workflow

The image building pipeline executes these steps in order. Each step uses the OpenStack SDK for Python to interact with cloud services.

Step 1: Create Build Instance

A temporary compute instance is created from a SLES base image. This instance serves as the build environment where the ISO will be downloaded and converted. The instance name follows the format proxmox-installer-{unix_timestamp}. 

import time
import openstack

# Connect using application credentials
conn = openstack.connect(cloud='ovh')

# Create the build instance
timestamp = int(time.time())
server = conn.compute.create_server(
    name=f"proxmox-installer-{timestamp}",
    image_id=conn.compute.find_image("SLES 15 SP5").id,
    flavor_id=conn.compute.find_flavor("b2-30").id,
    networks=[{"uuid": conn.network.find_network("Ext-Net").id}],
    key_name="my-key"
)

# Wait for the instance to become ACTIVE (timeout: 600s)
server = conn.compute.wait_for_server(server, wait=600)

Step 2: Download Proxmox ISO

Once the instance is active and SSH connectivity is established, the Proxmox ISO is downloaded to the build instance. The download is performed via SSH command execution with integrity verification based on expected file size. 

import paramiko

# Connect via SSH to the build instance
ip_address = server.access_ipv4
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect(ip_address, username="sles", key_filename="~/.ssh/id_rsa")

# Download the Proxmox ISO
iso_url = "https://download.proxmox.com/iso/proxmox-ve_8.2-1.iso"
download_cmd = f"wget -q -O /tmp/proxmox.iso {iso_url}"
stdin, stdout, stderr = ssh.exec_command(download_cmd, timeout=1800)
exit_status = stdout.channel.recv_exit_status()

if exit_status != 0:
    raise RuntimeError(f"ISO download failed: {stderr.read().decode()}")

# Verify file size integrity
stdin, stdout, stderr = ssh.exec_command("stat -c %s /tmp/proxmox.iso")
actual_size = int(stdout.read().decode().strip())
assert actual_size == expected_size, "ISO integrity check failed"

Step 3: Convert ISO to qcow2

The downloaded ISO is converted to qcow2 format using qemu-img convert. This produces a disk image compatible with OpenStack Glance. 

# Convert ISO to qcow2 format on the build instance
convert_cmd = "qemu-img convert -f raw -O qcow2 /tmp/proxmox.iso /tmp/proxmox.qcow2"
stdin, stdout, stderr = ssh.exec_command(convert_cmd, timeout=600)
exit_status = stdout.channel.recv_exit_status()

if exit_status != 0:
    error_output = stderr.read().decode()
    raise RuntimeError(f"Conversion failed: {error_output}")

# Verify output file exists and has content
stdin, stdout, stderr = ssh.exec_command("stat -c %s /tmp/proxmox.qcow2")
qcow2_size = int(stdout.read().decode().strip())
assert qcow2_size > 0, "qcow2 output file is empty"

Step 4: Create Server Snapshot

A server snapshot captures the state of the build instance, including the converted qcow2 file. The snapshot name follows the format proxmox-{version}-{YYYYMMDD-HHMMSS}. 

from datetime import datetime, timezone

# Create a snapshot of the build instance
build_time = datetime.now(timezone.utc).strftime("%Y%m%d-%H%M%S")
snapshot_name = f"proxmox-8.2-{build_time}"

snapshot_id = conn.compute.create_server_image(
    server.id,
    snapshot_name
)

# Wait for the snapshot to become ACTIVE
image = conn.image.wait_for_status(
    conn.image.get_image(snapshot_id),
    status="active",
    wait=1800
)

Step 5: Upload to Glance

The final qcow2 image is uploaded to OpenStack Glance with the appropriate metadata. Once uploaded, it becomes available as a bootable image in your project. 

# Upload the qcow2 image to Glance
image = conn.image.create_image(
    name="proxmox-ve-8.2-qcow2",
    disk_format="qcow2",
    container_format="bare",
    visibility="private",
    proxmox_version="8.2",
    build_timestamp=datetime.now(timezone.utc).isoformat()
)

# Upload the image data
conn.image.upload_image(
    image,
    data=open("/tmp/proxmox.qcow2", "rb")
)

# Wait for the image to reach ACTIVE status
image = conn.image.wait_for_status(image, status="active", wait=1800)
print(f"Image uploaded: {image.id} — {image.name}")

Configuration Reference

The build pipeline is configured via a YAML file. Below is the full schema with all available parameters: 

# image-build-config.yaml
image_build:
  iso_url: "https://download.proxmox.com/iso/proxmox-ve_8.2-1.iso"
  base_image_name: "SLES 15 SP5"
  flavor_name: "b2-30"
  target_image_name: "proxmox-ve-8.2-qcow2"
  proxmox_version: "8.2"
  target_visibility: "private"        # private | shared | public
  build_timeout: 1800                 # seconds (60–7200)
  iso_expected_size: 1200000000       # bytes (optional)
  iso_download_dir: "/tmp"
  iso_download_timeout: 1800
  conversion_timeout: 600
  snapshot_timeout: 1800

openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"
  auth_type: "v3applicationcredential"
  application_credential_id: "${OS_APPLICATION_CREDENTIAL_ID}"
  application_credential_secret: "${OS_APPLICATION_CREDENTIAL_SECRET}"

instance:
  ssh_key_name: "my-key"
  ssh_key_path: "~/.ssh/id_rsa"
  network_name: "Ext-Net"
ParameterRequiredDefaultDescription
iso_urlYes—HTTPS URL to Proxmox ISO file
base_image_nameYes—SLES image name in Glance
flavor_nameYes—Compute flavor for build instance
target_image_nameYes—Name for the final qcow2 image
target_visibilityNoprivateImage visibility (private/shared/public)
build_timeoutNo1800Build timeout in seconds (60–7200)
iso_expected_sizeNo—Expected ISO size in bytes for verification
iso_download_dirNo/tmpDownload directory on build instance

CLI Usage

The build-image subcommand triggers the full pipeline from the command line. It integrates with automation scripts and CI/CD pipelines. 

# Run the full image build pipeline
proxmox-automation build-image --config image-build-config.yaml

# Validate configuration without building (dry run)
proxmox-automation build-image --config image-build-config.yaml --dry-run

Exit codes:

  • 0 — Build completed successfully (image ID printed to stdout)
  • 1 — Build or configuration failure (error message on stderr)

Example output on success:

Image built successfully:
  ID:   a1b2c3d4-e5f6-7890-abcd-ef1234567890
  Name: proxmox-ve-8.2-qcow2
