Proxmox VE Installation

Difficulty: Intermediate · Estimated time: 30 min

This lesson covers the automated Proxmox VE installation on a Debian 12 system. The installer configures the hostname, adds the Proxmox repository, installs packages, sets the root password, and prepares the system for GPU passthrough.

1. Hostname Configuration

Proxmox requires a properly configured hostname with a resolvable FQDN:

# Set hostname
hostnamectl set-hostname proxmox

# Configure /etc/hosts
echo "127.0.0.1 localhost
192.168.1.100 proxmox.local proxmox" > /etc/hosts

2. Add Proxmox Repository

The tool adds the Proxmox VE no-subscription repository (for non-enterprise use): 

# Add GPG key
wget -qO /etc/apt/trusted.gpg.d/proxmox-release-bookworm.gpg \
  http://download.proxmox.com/debian/proxmox-release-bookworm.gpg

# Add repository (no-subscription for training)
echo "deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription" \
  > /etc/apt/sources.list.d/pve-install-repo.list

# Update package lists
apt-get update

3. Install Proxmox Packages

The main installation installs Proxmox VE along with supporting services: 

# Non-interactive installation
DEBIAN_FRONTEND=noninteractive apt-get install -y \
  proxmox-ve \
  postfix \
  open-iscsi \
  chrony

This step takes several minutes. The automation handles the timeout (default: 1200s).

4. Root Password

A root password is set for Proxmox Web UI access. If not specified in config, a secure 20-character random password is generated: 

# Set root password (done via chpasswd)
echo "root:YourSecurePassword" | chpasswd

5. Kernel Configuration

The original Debian kernel is removed in favor of the Proxmox kernel, which includes all necessary virtualization patches: 

# Remove Debian default kernel
apt-get remove -y linux-image-amd64 'linux-image-6.1*' || true

# Update GRUB
update-grub

6. Reboot

After installation, the system reboots into the Proxmox kernel. The automation waits and reconnects via SSH (as root).

7. Verification

After reboot, the tool verifies Proxmox is running correctly:

# Check Proxmox version
pveversion
# Output: pve-manager/8.2.x/...

# Check critical services
systemctl is-active pve-cluster   # active
systemctl is-active pvedaemon     # active
systemctl is-active pveproxy      # active

Web UI Access

After successful installation, the Proxmox Web UI is available at: 

https://<instance-ip>:8006

Login with root and the configured password.
