Baremetal Provisioning

Difficulty: Intermediate · Estimated time: 25 min

In this lesson, you'll learn how the automation provisions a baremetal GPU instance on OVHcloud OpenStack. The provisioner authenticates via application credentials, creates an instance with the specified flavor, and waits for SSH connectivity.

Authentication

The tool uses the OpenStack SDK with application credentials for authentication. This avoids storing username/password and provides scoped access. 

# config.yaml — OpenStack credentials section
openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"
  auth_type: "v3applicationcredential"
  application_credential_id: "${OS_APPLICATION_CREDENTIAL_ID}"
  application_credential_secret: "${OS_APPLICATION_CREDENTIAL_SECRET}"

Environment variables are resolved at runtime. Export them before running:

# Set your credentials
export OS_APPLICATION_CREDENTIAL_ID="your-credential-id"
export OS_APPLICATION_CREDENTIAL_SECRET="your-credential-secret"

Instance Specification

The instance is created with a Debian 12 base image on a GPU-enabled baremetal flavor. Key parameters:

ParameterDefaultDescription
base_image_nameDebian 12Base OS image for the instance
flavor_nameb3-8Baremetal flavor with GPU
ssh_key_name—Name of the SSH key in OpenStack
network_nameExt-NetNetwork to attach to
ssh_usernamedebianDefault user for SSH

Provisioning Workflow

The provisioner performs these steps:

  1. Authenticate to OpenStack API
  2. Create a server with the specified image, flavor, and key pair
  3. Wait for the instance status to become ACTIVE (timeout: 600s)
  4. Retrieve the instance IP address
  5. Establish an SSH connection (timeout: 300s)
# What the automation does (equivalent manual commands):
# Create the instance
openstack server create \
  --image "Debian 12" \
  --flavor "b3-8" \
  --key-name "my-key" \
  --network "Ext-Net" \
  --security-group "default" \
  proxmox-gpu-node

# Wait for it to be active
openstack server show proxmox-gpu-node -f value -c status

# Get the IP
openstack server show proxmox-gpu-node -f value -c addresses

SSH Connection

Once the instance is ready, the tool connects via SSH using the specified key. All subsequent steps (Proxmox install, GPU config) are performed over this connection. 

# Manual equivalent
ssh -i ~/.ssh/id_rsa debian@<instance-ip>

Timeouts

Configurable timeouts protect against hung provisioning:

timeouts:
  instance_ready: 600    # Max wait for instance ACTIVE
  ssh_connection: 300    # Max wait for SSH connectivity
  proxmox_install: 1200  # Max time for Proxmox installation
  reboot_wait: 300       # Max wait after reboot
  gpu_setup: 600         # Max time for GPU configuration
  vm_creation: 300       # Max time for VM creation
