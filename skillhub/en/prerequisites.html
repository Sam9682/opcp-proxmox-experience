Prerequisites

Difficulty: Beginner · Estimated time: 15 min

Before running the automation, make sure your environment meets the following requirements. This page walks you through each dependency and how to verify it.

1. Bash Environment

All exercises require a Bash environment. You can use:

  • GNU/Linux distributions (Ubuntu, Debian, CentOS, etc.)
  • macOS
  • Windows with WSL (Ubuntu recommended)
# If on Windows, install WSL Ubuntu
wsl --install -d Ubuntu

2. Python 3.9+

The automation tool requires Python 3.9 or higher:

# Check Python version
python3 --version

# Install pip if needed
sudo apt update && sudo apt install -y python3 python3-pip python3-venv

3. OpenStack CLI Client

The provisioning step uses the OpenStack SDK. Install it via pip: 

# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install the project (includes openstacksdk dependency)
pip install -e .

# Verify OpenStack SDK is available
python3 -c "import openstack; print(openstack.__version__)"

4. OpenStack Credentials

You need application credentials for your OVHcloud OpenStack project. Create a config.yaml file with your credentials: 

openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"
  auth_type: "v3applicationcredential"
  application_credential_id: "${OS_APPLICATION_CREDENTIAL_ID}"
  application_credential_secret: "${OS_APPLICATION_CREDENTIAL_SECRET}"

instance:
  base_image_name: "Debian 12"
  flavor_name: "b3-8"
  ssh_key_name: "my-key"
  ssh_key_path: "~/.ssh/id_rsa"

5. SSH Key Pair

You need an SSH key pair registered in your OpenStack project:

# Generate a key pair if you don't have one
ssh-keygen -t ed25519 -f ~/.ssh/id_proxmox -N ""

# Upload it to OpenStack
openstack keypair create --public-key ~/.ssh/id_proxmox.pub my-key

6. GPU Baremetal Flavor

Ensure your OpenStack project has access to a baremetal flavor with GPU. Common OVHcloud GPU flavors include b3-8 (NVIDIA T4). 

# List available flavors
openstack flavor list | grep -i gpu

Quick Validation

Run these commands to verify everything is ready:

# Check Python
python3 --version

# Check the tool is installed
proxmox-install --help

# Validate your configuration
proxmox-install install --config config.yaml --dry-run
