VM Creation with GPU

Difficulty: Advanced · Estimated time: 25 min

Now that GPU passthrough is configured, we create a VM in Proxmox with direct GPU access. The VM uses Q35 machine type and OVMF UEFI firmware — both required for PCIe passthrough.

VM Configuration

Key settings for a GPU passthrough VM:

ParameterValueWhy
Machine typeq35Supports PCIe passthrough natively
BIOSovmf (UEFI)Required for GPU initialization
CPU typehostExposes all CPU features to guest
Memory8192 MBSufficient for GPU workloads
Cores4Balanced for testing
SCSI controllervirtio-scsi-singleBest disk performance

Creating the VM

The automation uses qm (Proxmox VM manager) to create and configure the VM: 

# Create the VM
qm create 100 \
  --name gpu-test-vm \
  --memory 8192 \
  --cores 4 \
  --machine q35 \
  --bios ovmf \
  --ostype l26 \
  --net0 virtio,bridge=vmbr0 \
  --scsihw virtio-scsi-single \
  --scsi0 local-lvm:32,iothread=1 \
  --efidisk0 local-lvm:1,efitype=4m

Attaching the GPU

The GPU is attached via the hostpci configuration. Important flags:

  • pcie=1 — Use PCIe bus (not legacy PCI)
  • x-vga=1 — Mark as primary display adapter
# Attach GPU (PCI address without the 0000: domain prefix)
qm set 100 --hostpci0 41:00.0,pcie=1,x-vga=1

# Set CPU flags for passthrough compatibility
qm set 100 --cpu host,hidden=1,flags=+pcid

The hidden=1 flag hides KVM from the guest OS. Some NVIDIA drivers refuse to load in a VM without this flag.

EFI Disk

OVMF requires a dedicated EFI disk for storing UEFI variables (boot entries, secure boot state): 

# The efidisk0 is automatically created with:
# --efidisk0 local-lvm:1,efitype=4m

Starting the VM

# Start the VM
qm start 100

# Check VM status
qm status 100
# status: running

# View VM configuration
qm config 100

Installing a Guest OS

If an ISO is specified in the configuration, it's attached as a CD-ROM. You can also attach one manually: 

# Download an Ubuntu ISO to Proxmox storage
wget -P /var/lib/vz/template/iso/ \
  https://releases.ubuntu.com/22.04/ubuntu-22.04-live-server-amd64.iso

# Attach to VM
qm set 100 --cdrom local:iso/ubuntu-22.04-live-server-amd64.iso
