Cleanup Resources

Difficulty: Beginner · Estimated time: 10 min

After completing the training, clean up all created resources to avoid unnecessary charges. The automation includes a cleanup manager that tracks and destroys resources in the correct order.

Automated Cleanup

Use the --cleanup-only flag to destroy all resources:

# Run cleanup
proxmox-install --config config.yaml --cleanup-only

Manual Cleanup Steps

If you need to clean up manually, follow this order:

1. Destroy the Test VM (on Proxmox)

# SSH into the Proxmox host first
ssh root@<instance-ip>

# Stop and destroy the VM
qm stop 100
qm destroy 100 --purge

2. Delete the OpenStack Instance

# From your local machine
openstack server delete proxmox-gpu-node

# Verify deletion
openstack server list

3. Clean Up Floating IPs (if used)

# List floating IPs
openstack floating ip list

# Delete unused floating IPs
openstack floating ip delete <floating-ip-id>

4. Remove SSH Key (optional)

# If you created a dedicated key for this training
openstack keypair delete my-key

Cleanup Order

Always clean up in reverse order of creation:

  1. VMs inside Proxmox
  2. The baremetal instance itself
  3. Floating IPs
  4. Security groups (if custom ones were created)
  5. SSH keys (optional)

Verify Everything is Gone

# List all servers — should be empty
openstack server list

# List floating IPs — should be empty or only pre-existing ones
openstack floating ip list
