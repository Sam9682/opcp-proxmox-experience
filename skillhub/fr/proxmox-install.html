Installation Proxmox VE

Difficulté : Intermédiaire · Temps estimé : 30 min

Cette leçon couvre l'installation automatisée de Proxmox VE sur un système Debian 12. L'installeur configure le hostname, ajoute le dépôt Proxmox, installe les paquets, définit le mot de passe root et prépare le système pour le GPU passthrough.

1. Configuration du hostname

# Définir le hostname
hostnamectl set-hostname proxmox

# Configurer /etc/hosts
echo "127.0.0.1 localhost
192.168.1.100 proxmox.local proxmox" > /etc/hosts

2. Ajout du dépôt Proxmox

# Ajouter la clé GPG
wget -qO /etc/apt/trusted.gpg.d/proxmox-release-bookworm.gpg \
  http://download.proxmox.com/debian/proxmox-release-bookworm.gpg

# Ajouter le dépôt (no-subscription pour la formation)
echo "deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription" \
  > /etc/apt/sources.list.d/pve-install-repo.list

# Mettre à jour les listes de paquets
apt-get update

3. Installation des paquets Proxmox

# Installation non-interactive
DEBIAN_FRONTEND=noninteractive apt-get install -y \
  proxmox-ve \
  postfix \
  open-iscsi \
  chrony

4. Mot de passe root

Un mot de passe root est défini pour l'accès à l'interface Web Proxmox. S'il n'est pas spécifié dans la config, un mot de passe aléatoire sécurisé de 20 caractères est généré. 

# Définir le mot de passe root
echo "root:VotreMotDePasseSecurise" | chpasswd

5. Configuration du noyau

# Supprimer le noyau Debian par défaut
apt-get remove -y linux-image-amd64 'linux-image-6.1*' || true

# Mettre à jour GRUB
update-grub

6. Redémarrage

Après l'installation, le système redémarre sur le noyau Proxmox. L'automatisation attend et se reconnecte via SSH (en tant que root).

7. Vérification

# Vérifier la version Proxmox
pveversion

# Vérifier les services critiques
systemctl is-active pve-cluster   # active
systemctl is-active pvedaemon     # active
systemctl is-active pveproxy      # active
