Validation & Tests

Difficulté : Intermédiaire · Temps estimé : 20 min

Après avoir créé la VM avec GPU passthrough, la validation s'assure que tout fonctionne correctement. Cette leçon couvre la vérification de la visibilité GPU côté hôte et côté guest.

Vérification côté hôte

1. Vérification IOMMU

# Vérifier que IOMMU est actif
dmesg | grep -i iommu

# Lister les groupes IOMMU
find /sys/kernel/iommu_groups/ -maxdepth 1 -mindepth 1 -type d | wc -l

2. Vérification liaison VFIO

# Vérifier chaque GPU lié à vfio-pci
lspci -ks 41:00.0
# Kernel driver in use: vfio-pci  ← Attendu

3. Statut de la VM

# Vérifier que la VM tourne
qm status 100

# Voir la configuration
qm config 100 | grep hostpci

Vérification côté guest

1. Détection du périphérique PCI

# Dans la VM :
lspci | grep -i nvidia
# 01:00.0 3D controller: NVIDIA Corporation Tesla T4

2. Driver NVIDIA

# Installer les drivers NVIDIA dans la VM
apt install -y nvidia-driver-535

# Vérifier avec nvidia-smi
nvidia-smi

3. Test CUDA (optionnel)

# Installer le toolkit CUDA
apt install -y nvidia-cuda-toolkit

# Vérifier la version
nvcc --version

Problèmes courants

SymptômeCauseSolution
GPU non visible dans la VM hostpci non configuré Vérifier qm config
VM ne démarre pas GPU encore lié au driver hôte Vérifier lspci -ks montre vfio-pci
Erreur Code 43 (Windows) NVIDIA détecte l'hyperviseur S'assurer que le flag hidden=1 est défini
Écran noir sur sortie GPU BIOS pas en OVMF Changer le BIOS en OVMF (UEFI)

Test de performance

# Vérifier l'utilisation GPU pendant une charge
nvidia-smi dmon -s u -d 1

# Lancer un benchmark simple
python3 -c "
import torch
x = torch.randn(10000, 10000, device='cuda')
y = torch.matmul(x, x)
print('GPU compute OK:', y.shape)
"
