Prérequis

Difficulté : Débutant · Temps estimé : 15 min

Avant de lancer l'automatisation, assurez-vous que votre environnement respecte les exigences suivantes.

1. Environnement Bash

Tous les exercices nécessitent un environnement Bash :

  • Distributions GNU/Linux (Ubuntu, Debian, CentOS, etc.)
  • macOS
  • Windows avec WSL (Ubuntu recommandé)
# Si sous Windows, installer WSL Ubuntu
wsl --install -d Ubuntu

2. Python 3.9+

L'outil d'automatisation nécessite Python 3.9 ou supérieur :

# Vérifier la version de Python
python3 --version

# Installer pip si nécessaire
sudo apt update && sudo apt install -y python3 python3-pip python3-venv

3. Client CLI OpenStack

L'étape de provisionnement utilise le SDK OpenStack :

# Créer et activer un environnement virtuel
python3 -m venv .venv
source .venv/bin/activate

# Installer le projet (inclut la dépendance openstacksdk)
pip install -e .

# Vérifier que le SDK OpenStack est disponible
python3 -c "import openstack; print(openstack.__version__)"

4. Identifiants OpenStack

Vous avez besoin d'identifiants d'application pour votre projet OVHcloud OpenStack. Créez un fichier config.yaml : 

openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"
  auth_type: "v3applicationcredential"
  application_credential_id: "${OS_APPLICATION_CREDENTIAL_ID}"
  application_credential_secret: "${OS_APPLICATION_CREDENTIAL_SECRET}"

instance:
  base_image_name: "Debian 12"
  flavor_name: "b3-8"
  ssh_key_name: "my-key"
  ssh_key_path: "~/.ssh/id_rsa"

5. Paire de clés SSH

Vous avez besoin d'une paire de clés SSH enregistrée dans votre projet OpenStack :

# Générer une paire de clés
ssh-keygen -t ed25519 -f ~/.ssh/id_proxmox -N ""

# L'enregistrer dans OpenStack
openstack keypair create --public-key ~/.ssh/id_proxmox.pub my-key

6. Flavor Baremetal GPU

Assurez-vous que votre projet OpenStack a accès à un flavor baremetal avec GPU. Les flavors GPU OVHcloud courants incluent b3-8 (NVIDIA T4). 

# Lister les flavors disponibles
openstack flavor list | grep -i gpu

Validation rapide

# Vérifier Python
python3 --version

# Vérifier que l'outil est installé
proxmox-install --help

# Valider votre configuration
proxmox-install install --config config.yaml --dry-run
