Nettoyage des ressources

Difficulté : Débutant · Temps estimé : 10 min

Après avoir terminé la formation, nettoyez toutes les ressources créées pour éviter des frais inutiles.

Nettoyage automatisé

# Lancer le nettoyage
proxmox-install --config config.yaml --cleanup-only

Nettoyage manuel

1. Détruire la VM de test (sur Proxmox)

# Se connecter à l'hôte Proxmox
ssh root@<instance-ip>

# Arrêter et détruire la VM
qm stop 100
qm destroy 100 --purge

2. Supprimer l'instance OpenStack

# Depuis votre machine locale
openstack server delete proxmox-gpu-node

# Vérifier la suppression
openstack server list

3. Nettoyer les IP flottantes

# Lister les IP flottantes
openstack floating ip list

# Supprimer les IP flottantes inutilisées
openstack floating ip delete <floating-ip-id>

4. Supprimer la clé SSH (optionnel)

# Si vous avez créé une clé dédiée pour cette formation
openstack keypair delete my-key

Ordre de nettoyage

  1. VMs dans Proxmox
  2. L'instance baremetal elle-même
  3. IP flottantes
  4. Groupes de sécurité (si des personnalisés ont été créés)
  5. Clés SSH (optionnel)

Vérifier que tout est supprimé

# Lister tous les serveurs — devrait être vide
openstack server list

# Lister les IP flottantes
openstack floating ip list
