Création de VM avec GPU

Difficulté : Avancé · Temps estimé : 25 min

Maintenant que le GPU passthrough est configuré, nous créons une VM dans Proxmox avec accès GPU direct. La VM utilise le type machine Q35 et le firmware UEFI OVMF — tous deux requis pour le passthrough PCIe.

Configuration de la VM

ParamètreValeurPourquoi
Type machineq35Supporte le passthrough PCIe nativement
BIOSovmf (UEFI)Requis pour l'initialisation GPU
Type CPUhostExpose toutes les fonctionnalités CPU au guest
Mémoire8192 MoSuffisant pour les charges GPU
Cœurs4Équilibré pour les tests
Contrôleur SCSIvirtio-scsi-singleMeilleures performances disque

Création de la VM

# Créer la VM
qm create 100 \
  --name gpu-test-vm \
  --memory 8192 \
  --cores 4 \
  --machine q35 \
  --bios ovmf \
  --ostype l26 \
  --net0 virtio,bridge=vmbr0 \
  --scsihw virtio-scsi-single \
  --scsi0 local-lvm:32,iothread=1 \
  --efidisk0 local-lvm:1,efitype=4m

Attachement du GPU

  • pcie=1 — Utiliser le bus PCIe (pas PCI legacy)
  • x-vga=1 — Marquer comme adaptateur d'affichage principal
# Attacher le GPU (adresse PCI sans le préfixe domaine 0000:)
qm set 100 --hostpci0 41:00.0,pcie=1,x-vga=1

# Définir les flags CPU pour compatibilité passthrough
qm set 100 --cpu host,hidden=1,flags=+pcid

Le flag hidden=1 cache KVM au système guest. Certains drivers NVIDIA refusent de charger dans une VM sans ce flag.

Démarrage de la VM

# Démarrer la VM
qm start 100

# Vérifier le statut
qm status 100
# status: running

# Voir la configuration
qm config 100
