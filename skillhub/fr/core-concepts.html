Concepts Fondamentaux

Difficulté : Débutant · Temps estimé : 15 min

Avant de plonger dans les labs pratiques, comprenons les technologies clés qui rendent le GPU passthrough sur Proxmox possible.

Proxmox VE

Proxmox Virtual Environment est une plateforme de virtualisation serveur open-source basée sur Debian. Elle intègre l'hyperviseur KVM et les conteneurs LXC avec une interface web puissante, idéale pour exécuter des charges GPU dans des VMs.

  • KVM — Kernel-based Virtual Machine, fournit la virtualisation matérielle
  • QEMU — Émulateur de machine, gère l'émulation des périphériques VM
  • Q35 — Type de machine moderne supportant le passthrough PCIe
  • OVMF — Firmware UEFI pour les VMs (requis pour le GPU passthrough)

PCI Passthrough

Le PCI passthrough permet d'assigner directement un périphérique PCI physique (comme un GPU) à une machine virtuelle, en contournant l'hyperviseur. La VM obtient des performances quasi-natives du périphérique.

IOMMU (Input-Output Memory Management Unit)

L'IOMMU fournit l'isolation mémoire entre les périphériques et l'hôte. Il garantit qu'un périphérique passé en passthrough ne peut accéder qu'aux régions mémoire assignées à sa VM.

  • Intel VT-d — Implémentation IOMMU d'Intel (intel_iommu=on)
  • AMD-Vi — Implémentation IOMMU d'AMD (amd_iommu=on)
  • Groupes IOMMU — groupements logiques de périphériques PCI qui doivent être passés ensemble

VFIO (Virtual Function I/O)

VFIO est un framework noyau Linux qui fournit aux pilotes en espace utilisateur un accès direct aux périphériques. Pour le GPU passthrough, on lie le GPU au driver vfio-pci au lieu du driver GPU natif (ex: nouveau ou nvidia). 

# Vérifier la liaison driver actuelle
lspci -ks 41:00.0

# Attendu après liaison VFIO :
# Kernel driver in use: vfio-pci

Vue d'ensemble de l'architecture

Le workflow d'automatisation suit ces étapes :

ÉtapeComposantDescription
1ProvisionerCrée une instance baremetal sur OpenStack
2InstallerInstalle les paquets Proxmox VE sur Debian
3IOMMU ConfigActive IOMMU dans GRUB et charge les modules VFIO
4GPU DetectorDétecte les GPUs NVIDIA/AMD via lspci
5VFIO ManagerLie les GPUs au driver vfio-pci
6VM CreatorCrée une VM Q35/OVMF avec périphérique hostpci
7ValidatorVérifie que le GPU est visible dans la VM

Fichier de configuration clé

openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"

instance:
  base_image_name: "Debian 12"
  flavor_name: "b3-8"

proxmox:
  version: "8.2"
  enterprise_repo: false
  network_bridge: "vmbr0"

gpu_passthrough:
  enabled: true
  iommu_type: "intel"
  blacklist_drivers:
    - nouveau
    - nvidia
    - nvidiafb
    - nvidia_drm

test_vm:
  enabled: true
  name: "gpu-test-vm"
  memory_mb: 8192
  cores: 4
  machine_type: "q35"
  bios: "ovmf"
