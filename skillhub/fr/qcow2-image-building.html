Construction d'images qcow2 Proxmox

Difficulté : Avancé · Temps estimé : 40 min

Vue d'ensemble

Cette leçon couvre l'approche Python SDK pour construire des images disque Proxmox VE au format qcow2 sur OVH OpenStack. Le pipeline orchestre un workflow multi-étapes : créer une instance SLES temporaire, télécharger l'ISO Proxmox, convertir au format qcow2 avec qemu-img, créer un snapshot, et téléverser l'image finale vers OpenStack Glance.

À la fin de cette leçon, vous comprendrez comment automatiser l'intégralité du processus de construction d'image avec l'API Python OpenStack SDK et la sous-commande CLI build-image.

Prérequis

  • Identifiants OpenStack (application credentials ou nom d'utilisateur/mot de passe)
  • Python 3.9+ avec openstacksdk installé
  • Une paire de clés SSH enregistrée dans OpenStack
  • Accès à une image SLES de base dans OpenStack Glance
  • Familiarité avec les concepts de Provisionnement Baremetal

Workflow étape par étape

Le pipeline de construction d'image exécute ces étapes dans l'ordre. Chaque étape utilise le SDK OpenStack pour Python pour interagir avec les services cloud.

Étape 1 : Création de l'instance de build

Une instance de calcul temporaire est créée à partir d'une image SLES de base. Cette instance sert d'environnement de build où l'ISO sera téléchargé et converti. Le nom de l'instance suit le format proxmox-installer-{unix_timestamp}. 

import time
import openstack

# Connexion avec les application credentials
conn = openstack.connect(cloud='ovh')

# Créer l'instance de build
timestamp = int(time.time())
server = conn.compute.create_server(
    name=f"proxmox-installer-{timestamp}",
    image_id=conn.compute.find_image("SLES 15 SP5").id,
    flavor_id=conn.compute.find_flavor("b2-30").id,
    networks=[{"uuid": conn.network.find_network("Ext-Net").id}],
    key_name="my-key"
)

# Attendre que l'instance devienne ACTIVE (timeout : 600s)
server = conn.compute.wait_for_server(server, wait=600)

Étape 2 : Téléchargement de l'ISO Proxmox

Une fois l'instance active et la connectivité SSH établie, l'ISO Proxmox est téléchargé sur l'instance de build. Le téléchargement est effectué via une commande SSH avec vérification d'intégrité basée sur la taille de fichier attendue. 

import paramiko

# Connexion SSH à l'instance de build
ip_address = server.access_ipv4
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect(ip_address, username="sles", key_filename="~/.ssh/id_rsa")

# Télécharger l'ISO Proxmox
iso_url = "https://download.proxmox.com/iso/proxmox-ve_8.2-1.iso"
download_cmd = f"wget -q -O /tmp/proxmox.iso {iso_url}"
stdin, stdout, stderr = ssh.exec_command(download_cmd, timeout=1800)
exit_status = stdout.channel.recv_exit_status()

if exit_status != 0:
    raise RuntimeError(f"Échec du téléchargement ISO : {stderr.read().decode()}")

# Vérifier l'intégrité par la taille du fichier
stdin, stdout, stderr = ssh.exec_command("stat -c %s /tmp/proxmox.iso")
actual_size = int(stdout.read().decode().strip())
assert actual_size == expected_size, "Échec de la vérification d'intégrité ISO"

Étape 3 : Conversion de l'ISO en qcow2

L'ISO téléchargé est converti au format qcow2 avec qemu-img convert. Cela produit une image disque compatible avec OpenStack Glance. 

# Convertir l'ISO au format qcow2 sur l'instance de build
convert_cmd = "qemu-img convert -f raw -O qcow2 /tmp/proxmox.iso /tmp/proxmox.qcow2"
stdin, stdout, stderr = ssh.exec_command(convert_cmd, timeout=600)
exit_status = stdout.channel.recv_exit_status()

if exit_status != 0:
    error_output = stderr.read().decode()
    raise RuntimeError(f"Échec de la conversion : {error_output}")

# Vérifier que le fichier de sortie existe et a un contenu
stdin, stdout, stderr = ssh.exec_command("stat -c %s /tmp/proxmox.qcow2")
qcow2_size = int(stdout.read().decode().strip())
assert qcow2_size > 0, "Le fichier qcow2 de sortie est vide"

Étape 4 : Création du snapshot serveur

Un snapshot du serveur capture l'état de l'instance de build, y compris le fichier qcow2 converti. Le nom du snapshot suit le format proxmox-{version}-{AAAAMMJJ-HHMMSS}. 

from datetime import datetime, timezone

# Créer un snapshot de l'instance de build
build_time = datetime.now(timezone.utc).strftime("%Y%m%d-%H%M%S")
snapshot_name = f"proxmox-8.2-{build_time}"

snapshot_id = conn.compute.create_server_image(
    server.id,
    snapshot_name
)

# Attendre que le snapshot devienne ACTIVE
image = conn.image.wait_for_status(
    conn.image.get_image(snapshot_id),
    status="active",
    wait=1800
)

Étape 5 : Upload vers Glance

L'image qcow2 finale est téléversée vers OpenStack Glance avec les métadonnées appropriées. Une fois uploadée, elle devient disponible comme image bootable dans votre projet. 

# Téléverser l'image qcow2 vers Glance
image = conn.image.create_image(
    name="proxmox-ve-8.2-qcow2",
    disk_format="qcow2",
    container_format="bare",
    visibility="private",
    proxmox_version="8.2",
    build_timestamp=datetime.now(timezone.utc).isoformat()
)

# Téléverser les données de l'image
conn.image.upload_image(
    image,
    data=open("/tmp/proxmox.qcow2", "rb")
)

# Attendre que l'image atteigne le statut ACTIVE
image = conn.image.wait_for_status(image, status="active", wait=1800)
print(f"Image uploadée : {image.id} — {image.name}")

Référence de configuration

Le pipeline de build est configuré via un fichier YAML. Voici le schéma complet avec tous les paramètres disponibles : 

# image-build-config.yaml
image_build:
  iso_url: "https://download.proxmox.com/iso/proxmox-ve_8.2-1.iso"
  base_image_name: "SLES 15 SP5"
  flavor_name: "b2-30"
  target_image_name: "proxmox-ve-8.2-qcow2"
  proxmox_version: "8.2"
  target_visibility: "private"        # private | shared | public
  build_timeout: 1800                 # secondes (60–7200)
  iso_expected_size: 1200000000       # octets (optionnel)
  iso_download_dir: "/tmp"
  iso_download_timeout: 1800
  conversion_timeout: 600
  snapshot_timeout: 1800

openstack:
  auth_url: "https://auth.cloud.ovh.net/v3"
  region: "GRA9"
  auth_type: "v3applicationcredential"
  application_credential_id: "${OS_APPLICATION_CREDENTIAL_ID}"
  application_credential_secret: "${OS_APPLICATION_CREDENTIAL_SECRET}"

instance:
  ssh_key_name: "my-key"
  ssh_key_path: "~/.ssh/id_rsa"
  network_name: "Ext-Net"
ParamètreRequisDéfautDescription
iso_urlOui—URL HTTPS du fichier ISO Proxmox
base_image_nameOui—Nom de l'image SLES dans Glance
flavor_nameOui—Flavor de calcul pour l'instance de build
target_image_nameOui—Nom de l'image qcow2 finale
target_visibilityNonprivateVisibilité de l'image (private/shared/public)
build_timeoutNon1800Timeout de build en secondes (60–7200)
iso_expected_sizeNon—Taille ISO attendue en octets pour vérification
iso_download_dirNon/tmpRépertoire de téléchargement sur l'instance

Utilisation CLI

La sous-commande build-image déclenche le pipeline complet depuis la ligne de commande. Elle s'intègre aux scripts d'automatisation et aux pipelines CI/CD. 

# Exécuter le pipeline complet de construction d'image
proxmox-automation build-image --config image-build-config.yaml

# Valider la configuration sans construire (dry run)
proxmox-automation build-image --config image-build-config.yaml --dry-run

Codes de sortie :

  • 0 — Build terminé avec succès (ID de l'image affiché sur stdout)
  • 1 — Échec du build ou de la configuration (message d'erreur sur stderr)

Exemple de sortie en cas de succès :

Image built successfully:
  ID:   a1b2c3d4-e5f6-7890-abcd-ef1234567890
  Name: proxmox-ve-8.2-qcow2
