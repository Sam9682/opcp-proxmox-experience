GPU Passthrough (IOMMU & VFIO)

Difficulté : Avancé · Temps estimé : 35 min

C'est la leçon centrale de la formation. Vous apprendrez comment IOMMU et VFIO fonctionnent ensemble pour isoler les périphériques GPU de l'hôte et les rendre disponibles pour le passthrough VM.

Étape 1 : Détection GPU

# Détecter les contrôleurs VGA/3D
lspci -nn | grep -iE '(vga|3d|display)'

# Exemple de sortie :
# 41:00.0 3D controller [0302]: NVIDIA Corporation Tesla T4 [10de:1eb8] (rev a1)

Étape 2 : Configuration IOMMU

L'IOMMU doit être activé dans les paramètres kernel GRUB : 

# Pour CPUs Intel :
# GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt"

# Pour CPUs AMD :
# GRUB_CMDLINE_LINUX_DEFAULT="quiet amd_iommu=on iommu=pt"

# L'automatisation met à jour GRUB :
sed -i 's/GRUB_CMDLINE_LINUX_DEFAULT="\(.*\)"/GRUB_CMDLINE_LINUX_DEFAULT="\1 intel_iommu=on iommu=pt"/' /etc/default/grub
update-grub

Étape 3 : Modules noyau VFIO

# Modules requis (écrits dans /etc/modules-load.d/vfio.conf) :
vfio
vfio_iommu_type1
vfio_pci
vfio_virqfd

# Mettre à jour initramfs
update-initramfs -u -k all

Étape 4 : Blacklister les drivers GPU

# /etc/modprobe.d/blacklist-gpu.conf
blacklist nouveau
blacklist nvidia
blacklist nvidiafb
blacklist nvidia_drm

# S'assurer que VFIO charge en premier
softdep nouveau pre: vfio-pci
softdep nvidia pre: vfio-pci
softdep nvidiafb pre: vfio-pci
softdep nvidia_drm pre: vfio-pci

Étape 5 : Liaison VFIO-PCI

# /etc/modprobe.d/vfio.conf
options vfio-pci ids=10de:1eb8

Étape 6 : Règles Udev

# /etc/udev/rules.d/99-vfio.rules
ACTION=="add", ATTR{vendor}=="0x10de", ATTR{device}=="0x1eb8", DRIVER=="", ATTR{driver_override}="vfio-pci"

# Recharger les règles udev
udevadm control --reload-rules

Étape 7 : Vérification (après reboot)

# Vérifier que IOMMU est activé
dmesg | grep -i iommu | head -5

# Compter les groupes IOMMU
find /sys/kernel/iommu_groups/ -maxdepth 1 -mindepth 1 -type d | wc -l

# Vérifier que le GPU est lié à vfio-pci
lspci -ks 41:00.0
# Kernel driver in use: vfio-pci

Dépannage

  • IOMMU non activé : Vérifiez les paramètres BIOS/UEFI pour VT-d ou AMD-Vi
  • GPU toujours sur driver nvidia : Vérifiez que le blacklist est dans l'initramfs
  • Groupe IOMMU trop grand : Peut nécessiter un patch ACS override
  • Périphérique audio dans le même groupe : Passez les deux (GPU + audio)
