Proxmox VE GPU Passthrough sur Baremetal OVH

Bienvenue sur SkillHub, le compagnon de formation pratique du projet opcp-proxmox-install. Ce parcours vous guide à travers le déploiement de Proxmox VE sur des instances baremetal OVHcloud et la configuration du GPU PCI passthrough pour des charges de travail VM haute performance.

Contexte

Vous avez accès à un projet OVHcloud OpenStack avec des nœuds baremetal (GPU). À l'aide de notre outillage d'automatisation, vous allez provisionner une instance basée sur Debian, installer Proxmox VE, configurer IOMMU et VFIO pour l'isolation GPU, et créer une VM avec accès GPU direct — le tout automatisé via une seule commande CLI.

Ce que vous apprendrez

À la fin de ce parcours de formation, vous maîtriserez :

  • Concepts fondamentaux — Architecture Proxmox VE, fondamentaux du PCI passthrough et groupes IOMMU
  • Provisionnement Baremetal — création d'instances sur OVHcloud OpenStack avec des flavors GPU
  • Installation Proxmox — déploiement automatisé de Proxmox VE sur Debian
  • GPU Passthrough — configuration IOMMU, liaison driver VFIO et isolation des périphériques
  • Création de VM — création de VMs Q35/OVMF avec périphériques hostpci GPU
  • Validation — vérification de la visibilité GPU dans les VMs

Prérequis

  • Familiarité de base avec un terminal / ligne de commande
  • Python 3.9+ installé
  • Un projet OVHcloud Public Cloud avec accès baremetal GPU

Démarrage rapide

Installez l'outil d'automatisation et lancez le workflow complet :

# Cloner le projet
git clone https://forgejo.example.com/opcp-proxmox-install.git
cd opcp-proxmox-install

# Installer dans un environnement virtuel
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# Lancer l'automatisation (dry-run d'abord)
proxmox-install --config config.yaml --dry-run

# Exécuter le build complet
proxmox-install --config config.yaml
